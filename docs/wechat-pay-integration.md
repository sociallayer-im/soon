# Surf 微信小程序支付

采用普通商户 APIv3 JSAPI 下单与微信支付公钥验签。小程序调用 wx.requestPayment，服务器以验签后的回调或查单结果确认付款；客户端成功提示不直接发票。

## 2026-10-30 验签加固

- HTTP 响应在读取业务结果前验证原始正文、时间戳、nonce、签名及公钥 ID。
- 缺少签名、签名不符、超时和异常 JSON 视为结果未知，不作为确定的退款失败或未付款依据。
- 回调同样要求完整签名头，使用严格 Base64 解码；已有 AES-GCM 解密、通知去重和交易金额核对继续生效。
- 请求通过 Wechatpay-Serial 指定已配置的微信支付公钥 ID。

测试涵盖真实 RSA 签名、篡改正文、缺失头、过期签名、空 204 响应、错误响应，以及下单、回调、退款和购票流程。

验收边界：只读查单能验证商户请求签名与微信响应公钥，不能证明 AppID 绑定、真实下单或 APIv3 回调解密成功。最终需要真实小程序支付并验证到账状态、票券及退款。不得伪造支付成功回调到生产环境。

官方参数说明：https://pay.wechatpay.cn/doc/v3/merchant/4013070756
